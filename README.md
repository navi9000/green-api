# О проекте

Тестовое задание на позицию фронтенд разработчика. Проект подключает отправку сообщений в мессенджер max через сервис green-api. Внешне представляет собой упрощенную копию интерфейса чатов max.

В проекте реализованы 2 клиента отправки сообщений: один из них фиктивный (на github pages размещен именно он), а второй интегрирован с сервисом green-api.

Проект не сохраняет состояние при перезагрузке страницы

## Описание фиктивного клиента

Фиктивный клиент никуда не делает запросы и сразу возвращает успешний ответ.

Для авторизации нужно заполнить поля idInstance и apiTokenInstance любыми строками длиной от 1 символа. После авторизации откроется страница со списком чатов. Она будет пустая. Для добавления нового чата нужно нажать на плюс и заполнить открывшееся поле ввода любым числом. В список будет добавлен новый чат. При нажатии на чат из списка откроется страница чата. На ней можно написать сообщение. По истечении 30 секунд после последнего сообщения автоматически вернется ответ: "Информация получена"

## Описание клиента, связанного с сервисом green-api

Логика работы реального клиента повторяет логику фиктивного, но любые действия интегрированы с API сервиса green-api.

Для успешного запуска реального клиента необходима предварительная настройка. Сначала надо зарегистрироваться на странице этого сервиса: https://green-api.com/max После авторизации необходимо создать новый инстанс (create an instance). После успешного создания инстанса нужно перейти на его страницу. На ней нужно привязать инстанс к номеру телефона (get qr). Затем необходимо изменить настройки в разделе Webhooks: оставить пустым поле webhook url; установить ползунок Receive webhooks on incoming messages and files в значении "да". Затем необходимо создать файл .env на базе файла .env.example и отредактировать его значения. Параметр VITE_IS_REMOTE_CLIENT должен получить значение true, а параметр VITE_CHAT_API_URL должен получить значение apiUrl со страницы инстанса.

После этих приготовлений необходимо запустить проект с помощью команды `npm run dev`. Откроется страница авторизации. На ней необходимо ввести значения idInstance и apiTokenInstance со страницы инстанса.

Авторизация проверяет, авторизован ли инстанс через метод getStateInstance.
При добавлении номера телефона идет проверка, зарегистрирован ли такой номер в мессенджере max, через метод checkAccount.
Добавление сообщения реализовано через метод sendMessage.
Получение сообщений реализовано через методы receiveNotification и deleteNotification.

В случае получения ошибок в правом верхнем экране появляется сообщение с описанием ошибки.
